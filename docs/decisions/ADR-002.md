# ADR-002: NetworkX In-Memory Graph Processing

## Context
Payment risk detection requires identifying shared device/IP clusters across customer accounts in real time. We evaluated Neo4j, TigerGraph, and NetworkX.

## Decision
We choose **NetworkX** with in-memory graph indexing for local cluster detection.

## Consequences
- **Positive:** Sub-25ms graph cluster queries, zero external database setup overhead, seamless integration with Python data stack.
- **Negative:** Graph state must be periodically snapshot-persisted to prevent data loss on container restart.
