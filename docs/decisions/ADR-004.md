# ADR-004: State Machine Agent Framework

## Context
Unconstrained autonomous LLM agents can loop indefinitely, hallucinate non-existent evidence, or execute unverified actions.

## Decision
We implement the AI Investigator using an explicit **LangGraph State Machine** (`TRIAGE -> COLLECT -> HYPOTHESIZE -> VERIFY -> RECOMMEND -> POLICY_CHECK`).

## Consequences
- **Positive:** Fully deterministic state progression, 100% inspectable trace execution, guaranteed bounded runtime.
- **Negative:** Agent workflows must be explicitly modeled in code.
