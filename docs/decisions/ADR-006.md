# ADR-006: Least-Privilege Agent Tool Contracts

## Context
Agentic security requires enforcing strict boundary limits on tools available to LLMs.

## Decision
We enforce typed Pydantic tool schemas with strict separation between `READ_ONLY` context tools and `HIGH_IMPACT_REQUEST` policy request tools.

## Consequences
- **Positive:** Prevention of arbitrary data mutations or unauthorized tool misuse.
- **Negative:** Every tool must be defined with explicit input/output validation models.
