# ADR-001: Modular Monolith vs Microservices Architecture

## Context
RazorShield AI requires sub-50ms transaction risk evaluation latencies, high reliability, and clear end-to-end auditability. We evaluated building a distributed microservices architecture vs a modular monolith.

## Decision
We choose a **modular monolith** architecture using FastAPI (Python) for the backend and Next.js (TypeScript) for the frontend.

## Consequences
- **Positive:** Zero inter-service network serialization overhead, simplified deployment, straightforward test orchestration, high engineering signal.
- **Negative:** Shared process memory requires strict module boundaries to prevent tight coupling.
