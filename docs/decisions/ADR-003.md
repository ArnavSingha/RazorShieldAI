# ADR-003: Hybrid Risk Matrix vs LLM-Only Scoring

## Context
Many AI projects attempt to use an LLM directly for fraud scoring. We evaluated LLM-only scoring vs a hybrid tri-engine model (Rules + ML + Graph) with LLM as an out-of-band investigator.

## Decision
We enforce **Hybrid Tri-Engine Scoring** for real-time payment decisions, reserving the LLM strictly for out-of-band evidence correlation and analyst explanation.

## Consequences
- **Positive:** Sub-25ms deterministic scoring latency, immune to LLM hallucination or latency jitter during critical transaction path.
- **Negative:** Requires maintaining explicit feature extraction rules alongside ML models.
